## Nib 2.25.1

**If you call `nib` from a program, move up from 2.17.0–2.21.0.** Those releases switched off pdfcpu's configuration for every command (so a run writes nothing to `~/.config/pdfcpu`), and that quietly broke two things:

- text that nib itself draws — `nib stamp`, `nib pagenum`, the contents page, Markdown conversion — fell back to **unembedded** Base-14 fonts (the only trace was a log line);
- `nib fill` with **non-Latin** values (Cyrillic, CJK) failed with `font Roboto-Regular not available`.

2.25.x fixes both and keeps the promise: commands that only read or reuse a document (`fields`, `text`, `info`, `export-xfdf`, `merge`, `split`, `flatten`, `images`, and `fill`/`author` on ASCII values) touch no disk at all; the rest work in a scratch directory under the temporary directory that is removed when they finish. Nothing is written to your home or config directory.

### New since 2.21.0
- `nib author IN --fields F.json -o OUT` — add fillable fields, with optional default values.
- `nib stamp IN --stamps F.json -o OUT` — many text lines and pictures in one call.
- `nib merge --bookmark-per-file` — one bookmark per input, its own outline nested under it.
- `--no-clobber` on `nib fill --out-dir` and `nib split --out-dir`.

Everything is documented in `docs/cli-machine-readable.md`; `nib version --json` still reports `api` 1 (only additions). Verify a download against `SHA256SUMS`.
