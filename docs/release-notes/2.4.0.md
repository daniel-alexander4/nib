# Nib 2.4.0

This release carries pdfcpu v0.16.2 (up from v0.13.0) and moves the content digest a signing ceremony checks to rule 7.

## Read this before you update if a signing ceremony is open

**A ceremony begun on Nib 2.2.x or earlier cannot be finished on Nib 2.3 or later, and the reverse.** The two sides compute the document's digest differently, so they refuse each other. The older side only sees a refused connection that names no cause; the newer side says the other Nib is older.

- **Finish open ceremonies first.** Update only when every ceremony on this computer has ended. Nib 2.4.0's update window now tells you when one has not.
- **The build to finish on is the one you are running now.** Nothing offers an older build, so keep your current installer or binary until the ceremony ends. Downloading this release replaces nothing; installing it does. The last earlier build published here is [v2.2.0](https://github.com/daniel-alexander4/nib/releases/tag/v2.2.0).
- **A ceremony you cannot finish** can be convened again once everyone has updated — unless the document already carries a signature, which a new ceremony would not keep.
- A ceremony begun on 2.3 or later is only finished on 2.3 or later.

Documents already signed or finished are unaffected: a signature still verifies, and a finished document opens as before.

## What else changed

Nib's PDF library is now pdfcpu v0.16.2 as published (no local fork), with Go 1.26 as the floor for building from source. Documents that v0.13.0 mis-read now read correctly; a handful it read leniently are now refused by name. Details are in `docs/adr/174-nib-carries-pdfcpu-v0162-as-published-and-the-digest-moves-to-rule-7.md`.
