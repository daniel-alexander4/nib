## Nib 2.26.1

### Markdown templates (`nib office` / `nib import`)
- `--set KEY=VALUE` (repeatable) and `--set-file F.json` fill `{{key}}` placeholders in a Markdown document. A value goes in as **text**, never as Markdown. A key the template uses with no value is an error that names the key; braces that merely look like a placeholder, and a placeholder that formatting breaks in two, are errors too. `{{=key}}` prints the braces literally; code blocks are literal. Without `--set` braces are left alone.
- `--page-size letter|a4|legal` and `--margin POINTS` choose the page.
- `--type md` lets a Markdown document come on stdin (`-`); `nib import` is the same command as `nib office`.
- These options on a Word or OpenDocument file are refused, not ignored.

Not yet: GFM tables and local images in Markdown, and placeholders in DOCX/ODT (planned in `PLAN-import-export.md`, P01.S03).
