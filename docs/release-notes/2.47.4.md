## Nib 2.47.4

Nib now opens a good deal more than PDFs, and can write more than PDFs out.

Opening a file that is not a PDF turns it into one. That covers pictures (PNG, JPEG, TIFF, WebP, GIF, BMP, HEIC), comic archives, plain text, CSV and Markdown, Word, Excel, PowerPoint and OpenDocument files, PostScript, SVG, saved web pages, e-books and email. Markdown, text, CSV and pictures need nothing else. The rest use LibreOffice, Ghostscript, a HEIF decoder or a Chromium-family browser if you have one, and Nib says which when it is missing. Web pages, SVG, e-books and email are rebuilt from a short list of tags before a browser sees them, and opening one fetches nothing.

Going the other way, Document as… writes Markdown, a web page, plain text, Word, OpenDocument text, an e-book or a PowerPoint file, and Pages as images can write GIF, BMP, TIFF, comic archives, ZIP and a single page as SVG.

The Debian package now suggests LibreOffice, Ghostscript, poppler and libheif without installing them.
