## Nib 2.61.4

Nib can now change the pictures a page already draws.

Page Functions has a new Edit Objects tool. It outlines every picture on the page, and you can remove one, drag it somewhere else, resize it from a corner, nudge it with Shift and the arrow keys, or swap it for another picture with Replace…. A replacement keeps the old picture's place and its accessibility tag. Nib will not touch a signed document or one that is part of a signing ceremony, and it refuses a move it cannot make cleanly rather than guessing. The same edits are on the command line as `nib objects`, which can also list, remove and move drawings made of lines and shapes.

Secure has Inspect this file…, which shows what a document says about itself: its properties, its XMP metadata, its fonts, whether it claims to be tagged, and what the safety scan found.

Mark Up → Fill Forms from Data has Clear form, which puts every field back to the form's own default after asking first.

Scanned documents that store their pages as JBIG2, CCITT fax or JPEG 2000 pictures now show up. Before this release the window drew the page without the picture, so a copier scan could open looking almost blank.

`nib images` now reads pictures stored with ASCIIHex or ASCII85 encoding, and `nib images --out-dir -` writes every picture to standard output as one stream another program can read. `nib version --json` lists what this build can do under `capabilities`.
