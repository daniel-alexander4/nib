## Nib 2.29.0

### One list of the formats Nib opens
The extensions and MIME types for what Nib opens or converts used to be typed in nine places; they are now one table (ADR-184) and every picker reads it. Visible changes:

- The **Open dialog's folder listing now shows images** (PNG, JPEG, TIFF, WebP) beside PDFs — the routes behind it have opened them since 2.x, and the list hid them.
- On Linux, the **desktop entry** (`nib.desktop`) now offers Nib for those four image types as well as PDF.
- The Import and Combine file pickers are built from the table the app is running, so a format added later appears in both without a second edit. Nothing else about conversion changed.
