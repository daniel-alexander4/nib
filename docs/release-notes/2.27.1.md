## Nib 2.27.1

### GFM tables in Markdown (`nib office` / `nib import`)
A Markdown pipe table now converts to a real table instead of a paragraph of bars: columns sized to their text and wrapped to fit the page, a rule round every cell, a bold header row, and `:--` / `:-:` / `--:` alignment. It is tagged as a table (`Table` > `TR` > `TH` / `TD`, header cells scoped to their column), an empty cell is still a cell, and a row never splits across pages. `{{key}}` placeholders work inside cells. Refused rather than drawn wrongly: more than 24 columns, more than 5,000 rows, or a row taller than a page. A table that crosses a page does not repeat its header.

Still to come (planned in `PLAN-import-export.md`, P01.S03): local images in Markdown, and placeholders in DOCX/ODT.
