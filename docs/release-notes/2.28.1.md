## Nib 2.28.1

### Local images in Markdown (`nib office` / `nib import`)
`--image-dir DIR` embeds the pictures a Markdown document names: `![alt](logo.png)` reads a PNG or JPEG from `DIR`, places it after its paragraph, scaled **down** to the page (never up), and tags it as a `Figure` carrying the alt text (`{{key}}` works in it). A picture with empty alt text is decoration and an artifact. Without `--image-dir`, images are skipped exactly as before, so a document with web badges converts as it always did.

A source is refused, exit 1 naming it, unless it is a **relative path that stays under `DIR`**: a URL, a `data:` or `file:` reference, an absolute path, `..`, a symlink that leaves the folder, a file that is not a PNG or JPEG, one over 32 MiB or 100 megapixels, and a document naming more than 100 pictures. A document with a described picture and an undescribed one passes the PDF/UA checker (veraPDF).

Not placed: images inside a table cell. An image in the middle of a paragraph is placed after that paragraph's text.
