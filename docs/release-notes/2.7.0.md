# Nib 2.7.0

A signing ceremony's document check is now steady for documents whose fonts differ only in their subset tag.

Before, about 1 in 700 real documents could disagree with itself: the same bytes gave a different digest on different reads, so a party could be told a copy had changed when it had not. Ceremonies begun from this version use content-digest rule 8, which leaves the subset tag out. **Ceremonies already open on 2.5 or 2.6 (rule 7) finish as before; nothing needs finishing first.** A rule-7 ceremony over an affected document can still report a false change, as it did before; convene it again to move to rule 8.

A build older than 2.7.0 cannot take part in a ceremony begun on 2.7.0 or later and says so.
